# Gratitude Fitness Trainer

Landing page for Gratitude Fitness - premium 1-on-1 personal training studio in Kubwa, Abuja.

**Live site:** https://gratitude-fitness-trainer-264fd5217.vercel.app

## About

A conversion-focused single-page site for a personal training brand: bold Anton-typography hero, rating badge, results stats, six service cards, brand story, and a lead-capture consultation form.

## Features

- Bold editorial hero with lime accents and dual CTAs
- Stats band with Google rating, reviews and client counts
- Six service cards with hover lifts
- Sticky glass navbar with mobile menu
- Scroll-reveal animations and contact form wired to Supabase

## Stack

- HTML5 + Tailwind CSS (CDN)
- Vanilla JavaScript
- [Lucide](https://lucide.dev) icons
- Google Fonts
- Supabase Edge Function (contact form)
